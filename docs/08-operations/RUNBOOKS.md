# Runbooks

This repository does not yet operate production systems.

When production systems are added, every deployable app or service should have a runbook covering:

- purpose
- owners
- dependencies
- health checks
- local development
- deployment
- rollback
- monitoring
- alerts
- incident response
- backup/restore expectations
