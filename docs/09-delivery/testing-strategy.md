# Testing Strategy

## Initial State

The initial foundation uses verification scripts instead of application tests because no production apps or services exist yet.

## Future Testing Layers

- unit tests
- integration tests
- contract tests
- end-to-end tests
- smoke tests
- migration tests
- security tests
- accessibility tests
- performance tests
- resilience tests

## Rule

Testing requirements should be defined by project type in:

```text
governance/repo-contract/project-types.yaml
```
