# Work Packets

Work packets are scoped units of planned repository change.

Each work packet should include:

- goal
- scope
- non-goals
- files expected to change
- acceptance criteria
- verification commands
- rollback notes
- recommended atomic commit message

Work packets are intentionally plain Markdown at this stage.
