# Glossary

## ADR

Architecture Decision Record.

## App

A deployable user-facing application.

## Boundary

A rule describing which project types may depend on which other project types.

## Contract

A stable interface specification such as OpenAPI, event schema, or error format.

## Project

A declared repository unit with a type, path, owner, and lifecycle.

## Repo Contract

The rules the repository must obey.

## Workspace State

Machine-readable facts about the current repository.

## Work Packet

A small planned unit of work with scope, acceptance criteria, verification, and commit guidance.

## AI Context

Repository-maintained files that help an AI assistant understand the current state, constraints, and next step.
