# Security Model

## Baseline

Security is part of the repository foundation.

## Required Security Surfaces

- dependency policy
- secrets policy
- supply-chain planning
- SBOM planning
- data classification
- CodeQL planning
- security review triggers
- responsible disclosure

## Security Review Triggers

Security review is required for changes involving:

- authentication
- authorization
- cryptography
- secrets
- infrastructure
- audit logs
- data classification
- dependency trust
- public contracts
- release artifacts
