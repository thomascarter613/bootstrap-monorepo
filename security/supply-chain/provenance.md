# Provenance

Provenance records should describe where generated files, release artifacts, and future scaffolds came from.

Initial provenance location:

```text
workspace/provenance/
```

Future provenance may include:

- generator name
- generator version
- template name
- template version
- input parameters
- output paths
- verification result
